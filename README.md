# Fullstack Лабораторная работа №1 — Платформа «Обмен книгами» (BookShare)

Проект разработан в рамках 1-го семестра лабораторных работ по курсу «Fullstack».
Представляет собой фронтенд-каркас и пользовательский интерфейс для платформы книгообмена (BookShare).

---

## 📌 Назначение и Пользовательские Сценарии

Платформа «BookShare» предназначена для обмена книгами между студентами и преподавателями.

### Основные пользовательские сценарии:
1. **Просмотр каталога**: Навигация по выложенным книгам, поиск по названию/автору, фильтрация по жанрам и статусам («Доступна», «Забронирована», «Выдана», «Возвращена»).
2. **Просмотр деталей книги**: Отдельный экран с подробным описанием книги, параметрами (год, состояние, место передачи) и информацией о владельце.
3. **Бронирование книги**: Авторизованный пользователь может забронировать понравившуюся свободную книгу.
4. **Добавление и управление книгами**: Владелец может выставить свою книгу на обмен, отредактировать информацию или удалить её.
5. **Личный кабинет**: Отображение «Моих книг», «Забронированных мной книг» и полной «Истории обменов» с возможностью смены статуса обмена владельцем.
6. **Статистика**: Наглядная аналитика количества книг, активных обменов, зарегистрированных пользователей и распределения по жанрам.

## 🛠 Запуск проекта локально

### Предварительные требования:
- **Node.js** (v18+)
- **npm** (v9+)

### Шаги запуска:

1. Перейдите в каталог `frontend`:
   ```bash
   cd frontend
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте адрес `http://localhost:5173` в браузере.
