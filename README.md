# Fullstack Платформа «Обмен книгами» (BookShare) — Лабораторные работы №1–5 (Python Backend)

Полностью готовое fullstack-приложение для обмена книгами (**BookShare**), разработанное в рамках курса «Fullstack» (1 семестр). Проект включает клиентскую часть (React + Vite + TypeScript), серверную часть на **Python (FastAPI)**, реляционную базу данных (**SQLite + SQLAlchemy ORM**) с авторизацией JWT и хешированием паролей (bcrypt).

---

## 📚 Обзор выполненных лабораторных работ (Лабы 1–5)

### 🔹 Лабораторная работа №1: Проектирование UI/UX и Фронтенд-интерфейса
- **Задачи**: Разработка клиентского приложения, компонентов каталога, карточек книг, фильтров, форм добавления/редактирования, личного кабинета и страницы статистики.
- **Реализация**: React 18, Vite, TypeScript, Vanilla CSS (CSS Variables, Flexbox, Grid, Glassmorphic дизайн-система).

### 🔹 Лабораторная работа №2: Проектирование и Создание Реляционной Базы Данных на Python
- **Задачи**: Проектирование реляционной схемы данных (ER-модель), организация связей между пользователями, книгами и обменами/бронированиями, авто-генерация таблиц и сидирование тестовых данных.
- **Реализация**: Python 3, **SQLAlchemy ORM**, SQLite database (`bookshare.db`).
- **Сущности**:
  - `User`: `id`, `name`, `email` (unique), `password` (hashed bcrypt), `created_at`
  - `Book`: `id`, `title`, `author`, `genre`, `year`, `description`, `condition`, `pickup_location`, `status`, `owner_id`
  - `Booking`: `id`, `book_id`, `owner_id`, `recipient_id`, `booking_date`, `completion_date`, `status`

### 🔹 Лабораторная работа №3: Разработка RESTful Backend API на Python (FastAPI)
- **Задачи**: Создание серверного API для регистрации/авторизации пользователей, CRUD операций с книгами, управление статусами бронирования и генерация аналитики.
- **Реализация**: **Python (FastAPI + Uvicorn)**, PyJWT авторизация, bcrypt хеширование паролей, Pydantic схемы валидации.
- **Маршруты API**:
  - `POST /api/auth/register` — Регистрация нового пользователя
  - `POST /api/auth/login` — Авторизация и получение JWT токена
  - `GET /api/auth/me` — Информация о текущем авторизованном пользователе
  - `GET /api/books` — Получение каталога книг (с поиском `?search=` и фильтрацией по жанру/статусу)
  - `GET /api/books/:id` — Подробные данные книги
  - `POST /api/books` — Добавление книги владельцем (требует JWT)
  - `PUT /api/books/:id` — Редактирование книги (доступно только владельцу)
  - `DELETE /api/books/:id` — Удаление книги (доступно только владельцу)
  - `POST /api/exchanges/book/:bookId` — Бронирование книги
  - `PATCH /api/exchanges/:id/status` — Изменение статуса обмена владельцем («Забронирована», «Выдана», «Возвращена», «Доступна»)
  - `GET /api/exchanges/history` — История обменов пользователя
  - `GET /api/stats` — Статистика системы (всего книг, доступных, забронированных, завершённых обменов, пользователей, распределение по жанрам)

### 🔹 Лабораторная работа №4: Интеграция Frontend и Python Backend
- **Задачи**: Соединение клиентского приложения с REST API, сохранение авторизации (JWT в `localStorage`), обработка ошибок, асинхронная синхронизация состояния.
- **Реализация**: API клиент (`frontend/src/api.ts`), взаимодействующий с FastAPI сервером.

### 🔹 Лабораторная работа №5: Комплексное Тестирование, Аналитика и Оптимизация
- **Задачи**: Финальная сборка fullstack проекта, валидация форм, защита чужих данных, обработка исключительных ситуаций и составление документации по запуску.

## 🛠 Быстрый запуск проекта с нуля

### Предварительные требования:
- **Python 3.9+**
- **Node.js** (v18+)

### 1. Первоначальная установка и подготовка (Автоматический setup):

Из корневой папки выполните:

```bash
npm run setup
```

*Команда автоматически создаст виртуальное окружение Python venv, установит библиотеки (FastAPI, SQLAlchemy, PyJWT, bcrypt, pydantic), создаст базу данных SQLite и заполнит её начальными данными, а также установит зависимости React.*

---

### 2. Запуск приложения

Запустите Backend и Frontend в двух терминалах:

#### Терминал 1: Python FastAPI Backend (Порт 5001)
```bash
npm run dev:backend
```

#### Терминал 2: React Frontend (Порт 5173)
```bash
npm run dev:frontend
```

После запуска откройте в браузере: **`http://localhost:5173`**
