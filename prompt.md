
Создай fullstack веб-приложение на тему «Обмен книгами».

Идея проекта: пользователи могут добавлять книги, которые они готовы отдать или обменять, просматривать каталог, искать книги, бронировать понравившиеся книги и отслеживать состояние обмена.

Сделай проект максимально простым и понятным для учебной fullstack-лабораторной работы. Не добавляй ненужные сложные функции, микросервисы, платежи, внешние API или сложную бизнес-логику.

Основной функционал:

1. Авторизация и регистрация
   Пользователь может зарегистрироваться, войти в систему и выйти из аккаунта.
   У пользователя есть имя, email и пароль.

2. Каталог книг
   На главной странице отображается список доступных книг.
   Для каждой книги показывай:
   название;
   автора;
   жанр;
   год издания;
   описание;
   состояние книги;
   владельца;
   статус доступности.

Добавь поиск по названию и автору.
Добавь фильтрацию по жанру и статусу.

3. Добавление книги
   Авторизованный пользователь может добавить свою книгу.
   Форма должна содержать:
   название;
   автора;
   жанр;
   год издания;
   описание;
   состояние;
   место передачи.

После добавления книга появляется в каталоге.

4. Страница книги
   Сделай отдельную страницу с подробной информацией о книге.
   Показывай данные книги и пользователя, который её разместил.
   Если книга доступна, пользователь может нажать кнопку «Забронировать».

5. Бронирование
   Пользователь может забронировать доступную книгу.
   После бронирования её статус меняется на «Забронирована».
   Владелец книги видит информацию о бронировании.

Предусмотри простые статусы:
«Доступна»
«Забронирована»
«Выдана»
«Возвращена»

Владелец книги может изменить статус обмена.

6. Личный кабинет
   В личном кабинете пользователь должен видеть:
   мои книги;
   забронированные мной книги;
   историю обменов.

Пользователь может редактировать и удалять свои книги.

7. История
   Для каждого обмена сохраняй:
   книгу;
   владельца;
   получателя;
   дату бронирования;
   дату завершения;
   текущий статус.

8. Статистика
   Добавь простую страницу статистики:
   количество книг в системе;
   количество доступных книг;
   количество забронированных книг;
   количество завершённых обменов;
   количество пользователей.

Требования к интерфейсу:

Сделай современный, аккуратный и простой интерфейс.
Используй адаптивную вёрстку для компьютера и телефона.
Главная страница должна содержать навигацию, поиск, фильтры и карточки книг.
Используй понятные кнопки и сообщения об ошибках.
Не перегружай дизайн анимациями.

Требования к базе данных:

Используй реляционную базу данных.
Создай минимум следующие сущности:
User
Book
Booking или Exchange

Продумай связи между таблицами.
Пароли пользователей должны храниться безопасно в виде хеша.

Архитектура:

Раздели frontend и backend логически.
Backend должен предоставлять API для регистрации, авторизации, книг, бронирований и статистики.
Frontend должен обращаться к API и отображать полученные данные.

Если в задании не указан конкретный стек, используй простой и распространённый стек:
Frontend: React + Vite
Backend: Node.js + Express
Database: PostgreSQL
ORM: Prisma
CSS: обычный CSS или простой CSS-модульный подход.

Не используй TypeScript, если он не требуется заданием. Если конкретный стек указан в лабораторной работе, используй именно его вместо предложенного выше.

Сделай проект полностью запускаемым локально.

Создай:
структуру проекта;
frontend;
backend;
схему базы данных;
миграции;
API;
авторизацию;
страницы интерфейса;
тестовые данные/seed;
README с инструкцией по запуску.

Добавь обработку основных ошибок: неправильный логин, попытка забронировать уже забронированную книгу, отсутствие обязательных полей, попытка изменить чужую книгу и другие очевидные случаи.

Не усложняй проект сверх описанного функционала.

Очень важно: сначала проанализируй требования и предложи структуру проекта и базы данных. Затем реализуй проект целиком. После реализации проверь, что все основные сценарии работают и что проект можно запустить с нуля по инструкции README.
